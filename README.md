# Student Achievement Management System (C Language)

基于 C 语言实现的单向链表学生成绩管理系统。本项目旨在演示链表数据结构的应用、文件 I/O 操作以及健壮的输入处理机制。

## 🚀 项目功能
- **数据初始化**：批量创建学生记录。
- **增删查改**：
    - 支持按学号或姓名添加、查找及删除学生信息。
- **文件持久化**：
    - 支持将当前链表数据导出（导出为 `.dat` 文件）。
    - 支持从文件导入数据恢复链表状态。
- **数据浏览**：查看内存中所有存储的学生信息。
- **输入校验**：内置健壮的整数输入校验，防止程序因无效输入而崩溃。

## 🛠 技术栈
- **语言**: C语言 (C99/C11)
- **IDE**: Visual Studio (推荐)
- **编译器**: MSVC (Windows 环境下使用)
- **数据结构**: 单向链表

## 📦 如何运行
1. **环境要求**:
   - 确保安装了 C 语言编译器（Visual Studio 即可）。
   - 该项目使用了 Windows API (`system("cls")`, `system("pause")`)，建议在 Windows 环境下运行。

2. **编译与运行**:
   - 克隆本项目到本地。
   - 打开项目文件夹中的 `.sln` 文件（如果有）或在 VS 中创建一个空项目。
   - 将 `main.c` 和 `student.h` 加入项目。
   - 点击“运行”按钮即可。

## 📋 功能菜单说明
- `[1] 初始化数据`: 清空并重建链表。
- `[2] 新增数据`: 在链表末尾追加新学生。
- `[3] 删除数据`: 支持按学号或姓名删除。
- `[4] 查找数据`: 快速定位学生信息。
- `[5] 导出数据`: 保存链表数据到 `students.dat`。
- `[6] 导入数据`: 从 `students.dat` 恢复数据。
- `[7] 浏览数据`: 打印所有记录。
